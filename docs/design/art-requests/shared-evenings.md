# Shared evenings and resettlement art

> **Earlier release brief.** Reuse approved sources in the corresponding [four-act asset slot](../campaign-art-delivery.md). Current scene and encounter needs come from that release register.

Use the existing character, quarters and environment guides and the private CY31 draft. Replace placeholders under the
same asset IDs. Each prefix is the local port ID, `selden`, `orla`, `morrow`, `kestrel` or `vesper`.

| Asset ID pattern | In play | What to show |
|---|---|---|
| `<port>-lounge-evening` | First shared invitation, follow-up and later recruits' solo dates | Three chairs and the local keepsake from the script. Leave room for both portraits and the invitation overlay. |
| `<port>-lounge-morning` | Both milestone mornings and later recruits' solo mornings | The same lounge at first light. The keepsake stays in the same place. |
| `<port>-shared-cabin-layout` | Shared quarters move-in | Two bunks, a worktable and a locker for each occupant. Readable on both bond paths. |
| `<port>-private-cabin-layout` | Separate cabins move-in | A single bunk and a controlled door. Follow the established lighting cue for a welcome visit. |
| `<port>-local-watch-layout` | Visit after resettlement and defense | Two civilian workstations with the tools for their `home.jobs`. Use civilian watch gear and the local work board. |

Review the invitation, morning and follow-up with both friendship and romance dialogue. Keep the portraits legible at
iPhone size and match expressions to each character's agreement. After a move ashore, the local workroom should read
as a staffed civilian base. CY32's project art can build from that base and show civilian staffing when the pair stays aboard.
