# Existing campaign release checks

> **Historical release record.** Current sequencing and acceptance live in the [four-act roadmap](../four-act-roadmap.md).

Use a disposable copy of the current campaign profile while reviewing a new build or release.
Record tuning and presentation in [CY36](CY36.md) and physical-device findings in
[CY37](CY37.md).

| Case | Verify in the existing campaign |
| --- | --- |
| Recruitment and Training | Sign-on, optional Training, both issued main weapon choices, retry and resume, one debrief, first evening on either opening route. |
| Supply and upkeep | Port shipping, reserves, shortage recovery, drive refit, Back and hand fittings, and no repeat charge or duplicated materials on a resumed sortie. |
| Ship command | Paid escort, loss and free retry, resumed committed orders, objective integrity and correct cinematic reactions. |
| Legacy finale | Five case files in different orders, fleet readiness, both boarding entries, the two-console breach, civilian aftermath, and recovery of earlier saves. |
| Crew art | One shared batch check per template revision, exact approved bindings for all crew, board rendering and replay with multiple deployed rigs. |
