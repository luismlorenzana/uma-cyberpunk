# CY59 Art authoring · Crew combat sprites in batches

## Outcome

Create local draft bundles for the 50 crew outfits in the private roster using one compact
helmeted 2D production rig. The two reference exports, v012 and v015, are the working board
references. They already proved independent fittings, shared atlas pages and saved replay
together on Palinode. Use the [current bundle contract](../../technical/combat-sprite-bundles.md)
and the [39-part visual mapping](../combat-sprite-coverage.json).

## Art production

1. Generate the roster worklist from the latest approved wardrobe and local campaign release.
   It pins each canonical outfit, approved helmeted armor image and hash. It also records an
   existing local bundle or authored boarding route where available. All 50 can enter local
   production while their campaign chapters are being integrated.
2. Parameterize one deterministic source exporter with the character key, outfit ID, version
   and material palette. Keep the four board facings, foot and grip anchors, standard pose
   timeline, damage states and equipment sockets in the shared rig. Apply palette swaps to
   armor material ramps, visor/emissive accents and tail where the source calls for it.
   Preserve the approved helmet, emblem or other features that affect recognition at board
   size through small replaceable layers. Flag a changed silhouette or socket as an exception.
3. Build all eligible profiles in one run into fresh draft directories for the local Combat
   Sprites album. Keep the shared equipment families, grips, Back units, impacts and timing
   tied to the game cues. Export the same manifest format, placements and pinned pages for
   each identity. Use one contact sheet per tier at board size to review palettes, visual
   identity and exceptions.

## Game acceptance and release

Run the complete mechanic, fitting and reduced-motion proof when the shared template or
renderer changes. For regular palette and identity variants, verify source and export hashes,
canonical identity, dimensions, anchors, shared clip and 39-part coverage, and reproducibility
automatically across the batch. Run targeted board checks for variants that change geometry,
sockets, motion or layering. Sample a few ordinary variants together on the campaign board.

Stage every local review receipt in one command, then review and approve exact versions as a
batch. [CY57](CY57.md) owns board integration, [CY76](CY76.md) owns Platform and game
publication, and [CY37](CY37.md) owns physical iPhone testing. Boss and sub-boss motion and
scale use [CY79](CY79.md).

## Local batch result

All 50 crew drafts are selected in the local Combat Sprites album. The
[batch validation](../../../content/cy57-training-review/crew-palette-batch-v4/validation.json)
covers 250 atlas pages, shared registration and clips, and pixel changes inside the armor
masks. The [album playback check](../../../content/cy57-training-review/crew-palette-batch-v4/album-smoke.json)
opened and animated two drafts in the real gallery. Earlier versions remain available for
comparison. Exact release approval follows local review.
