# CY51 Development · Campaign ship rooms and resource-state art

## Outcome and dependencies

Make ship locations and planetary development visibly reflect the management loop on the existing
campaign save. Start after CY48's first integrated four-scene checkpoint and reuse its presentation
contract. Read the [delivery plan](../../design/campaign-art-delivery.md), [CY52 Art](CY52.md),
[CY53 Story](CY53.md), port supply, projects, workshop and ship manual. P1's roster art rollout can
continue alongside this work.

## Implementation

1. Inventory every current campaign entry that actually opens a ship room, supply operation, refit,
   workshop or civilian project. Record its existing ID and state predicate. Separate reachable
   features from concept-only rooms. Agree with CY52/CY53 which visual-only plates can support a
   scene without adding an interactive room or new economy rule.
2. Bind room assets through the existing private content mechanism, extending it additively when
   required. Reuse P1 meeting/cabin plates and portrait policy. Provide bridge/briefing, living/social,
   care/custody and operations families with explicit fallback IDs. Avoid eagerly downloading the
   entire ship image library on launch.
3. Define state-driven art for under-construction/completed projects, damaged/repaired modules where
   those states exist, received shipments and fitted equipment. The saved domain state chooses the
   picture. Verify a completion image cannot appear while resources are still reserved for a project.
   Keep the numeric ledger and costs authoritative and visible before confirmation.
4. Integrate one actual port export into a funded gear fitting and a ship refit. Show the cargo and
   facility context in the corresponding existing panels/scenes. Keep local reserves, port upkeep,
   ship upkeep and build completion in their established nightly order. Replacing art must not
   create production or consume a second shipment. Add new rules only through a separate brief change.
5. Use concise routine feedback and reserve an optional authored location beat for a meaningful first
   completion or civilian handover. CY53 supplies occurrence rules. Save any once-only acknowledgement
   separately from whether the player has downloaded the artwork.
6. Integrate draft plates and short draft lines immediately, publish a private candidate, then replace
   approved files under stable IDs. Record every accepted room/state binding and any feature still
   lacking art in the shared record. Update the actual format and management manual.

## Verification

Exercise exact-fit and insufficient resources, local reserve protection, completion at night,
shortage recovery, cancellation where supported and duplicate completion. Check old and new pack
behavior, pending projects over reload and a pack swap while inspecting a room. Verify the visible
state after the actual shipment/refit rather than a debug flag. The fitted equipment must carry into
the next real boarding mission.

Review the ship and one base at 844 × 390 with 44 pt controls and safe areas. Check that decorations
do not imply unavailable interactions. Run affected state/pack tests, lint, full tests and build for
the implementation. Record physical-device findings for CY37.

## Done when

Every agreed reachable room/state has a declared binding or named draft fallback, the funded prep
sequence plays from the campaign and saved management state matches its art after resume. CY52/CY53
handoffs are wired by revision and outstanding final authoring is explicit. Delete with a Done row.
