## Handoff shape and review

Return a private path or pinned export with its base content release, source revision, date and editorial verdict. The following are required logical fields. CY116 will connect the accepted rows to the runtime format, so keep stable IDs from existing scenes and report an old-to-new reference for any approved replacement.

- **Scenes** — source scene/quest ID, chapter/branch, act, prerequisites, actor IDs with role and required presence, place and vessel, eligible phase or due-watch basis, choices and committed result, exact entry and return scene, repeatability/recovery. Mark each row unchanged, retimed, re-staged, replaced or new with its reason and approval. Match any timed art to the actual step and branch.
- **Calendar** — locale or in-world label, stable month/calendar/event ID, ordered duration, relative or recurring date/watch, eligible actors/story prerequisites, location, advance cost if applicable, announcement, late/fallback path and exact scenes.
- **Route and battle** — stable system, port, duo, station or cutter, encounter, mission, approach and landing IDs. Include unit and operator roles, timing, branch, return or withdrawal disposition, cinematic and ground objectives, outcome and relevant scenes.
- **Art ledger** — setting key, reuse or new reason, referenced approved asset if known, actor role/outfit/expression, when and where it appears, alternate outcome, authoring owner and approval. Group shared environments.
- **Coverage receipt** — 50 personal, 50 General, 150 Lieutenant, 25 duo/cutter, 5 capitals and Act IV. Track exceptions and exact open questions. Return one playable example with each new handoff contract before batching similar rows.
