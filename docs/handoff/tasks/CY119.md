# CY119 · Campaign clock and work calendar

**Milestone B · Engineering with Story.** Implements CY116 clock semantics and CY126's approved calendar definitions.

- Replace independent day/watch advancement in the active campaign with a single transition service. Map construction, shift jobs, port production, daily upkeep, strain, scenes and committed mission time into explicit due boundaries. Apply each effect once and resolve due work, transit and deferred scenes in a stable order. Display dates and elapsed watches. Preserve the current cabin/overnight replay and recovery entry points.
- Build Today, Next 7 days and month/year views from the live save and authored event definitions. Expose actual state and projections, source location and in-context action, with recent past output records. Include bounded summaries for crowded days and announcements for relevant changes.
- Adapt Farm's forecast/results workflow. Support recurring shifts, manual reservations and auto-fill of remaining assignments. Use role, skill, presence, clearance, overlapping travel/operations, recovery and supplies to report eligible crew and output. Keep missing stock, unassigned positions and insufficient power legible as different failure reasons. Queue and forecast use the same rules as settlement.
- Add authored observances, birthdays where supplied, liberation/commissioning anniversaries, non-expiring required scenes, and configurable date windows with valid fallback. Use dates relative to the common calendar by default.

**Acceptance.** Show distinct work and relationship activity on one agenda. Measure 7-day forecast accuracy across funded, unstaffed, depowered, repositioned and absent-crew cases. Run day/month/year rollover, concurrent assignments, partial travel, no double settlement across retries/reloads, and full-population projection. Play an evening and morning to prove an existing authored overnight advances time correctly.
