## Authoring work

1. Review the current ship bible and approved masters with CY53. Establish a location sheet showing
   spatial relationships, recurring doors/windows, lighting and materials. Return layout conflicts
   before drawing. Use the existing Cyberpunk style and the same ship as P1.
2. Author common plates with quiet dialogue and management-panel areas. Cabin variants keep the same
   furniture anchors as CY49. Preserve the existing background when it already satisfies the shot;
   record any approved reuse by hash. Day/evening/morning variants share geometry.
3. From CY51's actual state list, produce construction/completion and repair variants only where the
   game stores that distinction. Keep local civilian ownership visible after liberation. A building
   state can use a prop/layer swap rather than another full painting.
4. Create readable resources, cargo, refit and workshop props matched to the real recipe/ledger IDs.
   Coordinate weapons and equipment with CY58; those canonical designs supply their icons. Do not
   invent a visually distinct resource that has no game or story meaning.
5. Complete the first port shipment, fitting and refit sequence as a set. Review its images in the
   actual panels and scene transitions before expanding across the five systems and later services.
