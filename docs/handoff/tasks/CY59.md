# CY59 Art authoring · Armored playable sprites and compatible action poses

## Outcome and dependencies

Create the playable roster's armored combat sprites for real campaign fights, with equipment supplied
by CY58 and assembled by CY57. Read the [delivery contract](../../design/campaign-art-delivery.md),
[CY57](CY57.md), [CY58](CY58.md), [CY63 Story](CY63.md), the existing
[combat image request](../../design/combat-sprites-request.md) and current approved armor/helmet art.
Reconcile the earlier empty-hand sheet request with the implemented attachment fixture before bulk work.

## Authoring work

1. Inventory existing authored and approved combat sets in the character Combat Sprites categories.
   Match exact scored outfit IDs, including distinct sister variants. Do not recreate approved work
   or count an original-outfit fallback as a commissioned Cyberpunk armor set.
2. Establish the first real recruit's identity and standing/walking sheets in approved armor. Use the
   existing chibi proportions, foot point, four drawn facings and asymmetric details. Carry any
   source-resolution change through CY57's fixture; preserve native unmodified masters and hashes.
3. Author act, hurt, guard, kneel/reboot and victory poses required by the implementation. Separate
   compatible arm/hand poses for melee, thrust, two-handed heavy, firearm, shield, mounted action and
   support as necessary. Reuse body frames where valid. Empty hands receive CY58 equipment, with
   visible contact at both grips for a two-handed weapon.
4. Derive helmet-on versions from approved armor poses where the supported campaign policy requires
   them. Keep body, equipment positions, identity colors and tail continuity. Never mirror an
   asymmetric face/accessory/weapon to fabricate a facing.
5. Preview the actual fitted equipment and layer order in the first campaign boarding mission.
   Review front/back recognition, weapon silhouette, cover, damaged/disabled equipment and kneeling.
   Correct the fixture/poses together before expanding to the second recruit and each later tier.
6. Expand to all fifty playable identities with status per body/look/action family, compatible parts
   and intended encounters. Additional unsupported animation states remain planned requests.
   Shared palette/pose techniques preserve each character's head, ears, accessories and proportions.

## Review and return

Use the existing owner-review sequence for identity, walks and actions. Return native sheets with
frame order, alpha, body/look and animation/facing IDs, foot/hand/mount anchors, subject bounds,
helmet variants, palette masks, SHA-256 and approvals. Export through the CY57 versioned format,
with the source master retained. Do not hand-align a single frame in the game without updating its
metadata and export source.

Inspect sprites around their actual phone display size on light/dark board areas, behind cover,
beside earlier fallback figures and during the required weapon motions. The game supplies ring,
shadow and effects. Keep those out of the raw figure images.

## Done when

All required playable sets have approved identity and action coverage, compatible attachment exports
and reviewed in-game evidence. The first funded loadout and representative later-tier rigs read
correctly after reload and a pack change. Required missing sets remain explicit until authored;
physical device performance is recorded through CY57/CY37. Delete with a Done row.
