# CY43 Far Meridian return routes and ferry search

## Why

Make an independently verified return route and a missing ferry two distinct problems the Captain can solve.

## Context

Use the private Far Meridian and case-ledger briefs, [CY42](CY42.md), and the travel and target contracts in [CY32](CY32.md) and [CY33](CY33.md).

## Game implementation

- Play the return-passage approach and the separate ferry search through bridge and ground objectives and both appointments. Link the verified route and any follow-on capability to the return-passage outcome. Show the actual ferry and the protected berth while applying the search outcome separately.
- File the original and altered chart as the required case and the ferry testimony as corroboration. Carry each status to the shared port and show the joint departure watch after the two appointments.

## Story and art

Stage the old chart, changed bearing and paper berth schedule as separate evidence. Distinguish ferries, escorts and relay targets at phone size. Use the return route cue again when the later fleet needs it.

## Done when

Finish both orders from the same fresh port state. After resolving one, the other remains available with the correct briefing. Verify route access, retry costs, testimony and the joint watch across reload. The required case still files if the search is deferred.
