1. Read the currently selected campaign and upstream code. Compare the latest Story and Art manifests with the private CY90 candidate. Integrate the latest approvals and write one combined release.
2. Compile with full four-act validation. Fix any real route, scene, art, encounter, or saved-state mismatch. Check the fresh opening through the normal game controls.
3. Run a continuous fresh-save route through the four acts using actual game actions and the saved results of each encounter. Batch-check the 50 solo openings, all fixed duos, capital settlements and expeditions. Exercise both Lark arrivals, solo and shared civic and relationship visits, loss, retreat, retry, reload and post-Lark repair.
4. Run lint, tests, production builds, private-content guards and startup-size checks. Check landscape layout, touch targets, art loading, first deployment, reconnect and resume in a mobile viewport.
5. Stage and hash-verify the exact campaign and assets. Record the prior selected manifest for a possible rollback. Open the game pull request, complete CI, merge, and monitor the existing web and API deployment.
6. Verify the deployed reader and API build. Select the new four-act manifest with the expected-current check. Read back the exact selected bytes and open the usual game link in a clean mobile browser.
