3. Run a continuous fresh-save route through the four acts using actual game actions and the saved results of each encounter. Batch-check the 50 solo openings, all fixed duos, capital settlements and expeditions. 4. Run lint, tests, production builds, private-content guards and startup-size checks. Check landscape layout, touch targets, art loading, first deployment, reconnect and resume in a mobile viewport.

6. Verify the deployed reader and API build. Select the new four-act manifest with the expected-current check. Read back the exact selected bytes and open the usual game link in a clean mobile browser.
