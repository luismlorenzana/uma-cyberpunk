# CY111 · Shared campaign environments

**General Art in the Cyberpunk workspace.** The campaign uses a library of 5–10 reusable setting images across all four acts. Choose approved art for the welcome and public interior, bridge, medbay, training, port and quarters. Keep day, evening and sleeping plates only where the scene framing needs them.

- Assign by what the player sees. A clinic can use the shared medical interior, a loading or transfer space can use the port, and working rooms can use the shared public interior. Reuse the chosen setting across a base’s opening, work and liberation scenes. Scene text, map markers and existing progress controls show what changed.
- Reuse the landing image for the matching navigation detail. Preserve the authored route geometry, encounter maps, current resources and settlement states. Keep individual character splashes and combat effects in their respective art libraries.
- Review the existing library on a phone before proposing a replacement. Use the current style and dialogue framing. Return the exact image and hash, the setting it replaces, and the scene or screen IDs used in review.
- The earlier per-base and planetary drafts are local review material. Do not send the draft batches through the game publisher.

**Integration.** Validate the shared set against all five systems and confirm that exact character splash compositions and timed scene cuts keep their source images.
