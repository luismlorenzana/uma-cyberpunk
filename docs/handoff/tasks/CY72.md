# CY72 Development · Isolate the restructured campaign pilot

## Outcome

Open the scripted pilot in the landscape campaign with its own release, save, cached pointer and
progress. The current Tier 1–5 campaign stays available as a separate entry. The pilot keeps the
same tactics, ship, recruitment and story-scene engines. Covers G3 and G13 and supplies the pilot
entry and dependency graph for CY73–CY75.

Read the Story game plan and the source pins in
`content/implementation-intake-2026-11-22/README.md`. The raw Story pool passed the story
parser. Its chapters still need a standalone campaign config, encounters and playable gates.

## Implementation

1. Introduce an allowlisted campaign identity at app entry. Carry it through the dev preview,
   authenticated content route, selected release pointer, device store, offline release cache,
   safety copies and server save repository. Default historical keys and endpoints to the existing
   campaign. Scope revision checks, restore, in-flight sync and network retries to the campaign
   and owner. Use full navigation when switching. Exercise both identities with the same account.
2. Compile the pilot from an explicit, hash-pinned allowlist of Story sources and the required
   cast, worlds, logs and art. Generate a private campaign config with a shared opening,
   accessible pre-recruitment background scenes, direct sign-on, and a roster route through the
   personal journey. Preserve the single-join rule. Express chapter prerequisites as executable
   campaign gates. Record completion only after required scenes, encounters and debriefs settle.
3. Route each beat through the existing scene player, commander encounter or ground encounter.
   Validate links, chapter prerequisites, mission start points and objective types at pack time.
   Allow a local candidate for completed beats while dependent packets land. Show a clear endpoint
   in any deliberately partial preview. Preserve each real Story beat ID and source hash.
4. Wire shared scene art and palette fallbacks from the current campaign with CY77/CY78. Require
   a Story-reviewed staging reference for reused settings. Keep Captain speech in authored player
   choices and validate the pilot's voice and scene constraints with Story.
