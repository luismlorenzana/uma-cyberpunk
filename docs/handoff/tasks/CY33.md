# CY33 Officer specialties and fighter objectives

## Why

Let officer development and fighter assignments change how the Captain approaches a ship encounter.

## Context

Use [CY32](CY32.md) for ship preparation and the [command contract](../../technical/campaign-content.md#ship-command). Exercise the change on the Selden convoy and occupied approach, then carry it to the gate.

## Game implementation

- Store learned skills by officer and specialty so a reassignment retains training. Use the four existing jobs and make proficiency change a concrete order. Keep a watch officer available at each vacant station.
- Give fighters an interception order and a targeted run against an authored ship or station system. Use distinct preparation for the fighter group and the bridge. Let the player inspect each target's consequence before the run. Author a normal victory and a system-disabled victory with different tactical entries.
- Version and freeze changed launch and action inputs. Keep earlier encounters readable and resumable. Carry paid preparation and assignments through retries. Use existing capacity, reactor pips and shields so the player can read action costs and options together.

## Story and art

Write distinct calls for ready, damaged, disabled and recovered system states that occur in the selected sorties. Give the fighter, target and protected civilian ship clearly different silhouettes. Agree on event and asset IDs with CY34 before shipping the first cues.

## Done when

Train an officer on one sortie, reassign her and see the retained skill affect a later order. Confirm a fighter-led target result changes the boarding or station entry. Demonstrate the regular win, loss, free retry and reload on a paid campaign sortie.
