2. Map to explicit campaign, scene and optional confirmed branch/beat, with layering policy and

   existing command cinematics for activity triggered by a committed ship result. Extend
   presentation metadata for a within-scene visual change only where a matched Story beat
   requires it. Pin the step/branch to the Story revision and report remaps when it changes.
3. Start with an available Crew meeting, seated cabin visit and accepted stay, plus a matching
   Boss Ally recovery or cabin scene. Continue with a Battle Station appearance scoped to the
   committed command result. Use the same contract for controlled enemy appearances,
   retreat/capture outcomes and trio scenes as sources land. The approved crew catalog also
   includes expression and pose variations. Review each against the actual scene's place,
   costume and action. Record approval separately for a new scene destination.
4. Preserve authored native masters and per-variant crops. Use the accepted aspect ratio on
   the landscape phone layout, with explicit dialogue/portrait overlay behavior and safe caption
   space. Missing, unapproved or incompatible art uses the existing authored scene presentation.
   Confirm leave/retry/cancel results continue to select their actual branches.
