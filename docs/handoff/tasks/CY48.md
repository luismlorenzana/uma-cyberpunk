# CY48 Development · Four relationship splash scenes

## Outcome and linked work

Deliver meeting, confession, seated cabin chat and an explicit stay-overnight flow in the real
combined campaign. Start with its first recruit, then a second independently available recruit,
and expand the bindings through all fifty Captain arcs. Read the
[delivery contract](../../design/campaign-art-delivery.md), [CY49 Art](CY49.md) and
[CY50 Story](CY50.md). This is the first implementation packet in the new queue.

## Starting points

Use `apps/web/src/story/ScenePlayer.tsx`, `ScenePortrait.tsx`, the campaign scene loader and evening
controllers, `packages/domain/src/story/campaign-dates.ts`, `campaign-pairs.ts`, the day reducer,
save migrations and `scripts/story/campaign.ts`. The existing illustration mode suppresses the
talking portrait. Repeatable dates exist; a distinct chat-to-bed choice is not implemented.
The private scene inventory maps the three existing families and explicitly marks new overnight beats.

The parallel publishing delivery implements the [scoped art pipeline](../../technical/campaign-art-publishing.md)
and the optional scene-composition contract. Approved sources can replace registered game assets
without changing the selected story. This supplies the presentation foundation in steps 1–2 below;
the stay/leave state flow, new draft scripts and complete roster/paired rollout still require this packet.

## Implementation

1. With CY49/CY50, implement one additive, validated presentation contract for a backdrop, optional
   pose/CG, optional props/effects and an explicit talking-portrait policy. Define native sizes,
   anchors, draw order and safe-area behavior in an executable synthetic fixture. Support a flattened
   illustration and layered art. Preserve earlier illustration and face-crop behavior by default.
2. Extend the private pack's checking, dependency collection, hash packing and client loading. Validate
   referenced assets, bounded placements, duplicate IDs and unsupported revisions. Preload just the
   scene's required images, release resources on exit and provide a readable fallback for failed art.
   Do not require a new shared package for game-local scene composition.
3. Bind meeting art to existing sign-on scenes. Stage the shared welcome/briefing room while retaining
   the actual port, quest prerequisites, join-once effect and roster-launched operation. Bind confession
   art to the existing relationship choice, coordinated with CY50's Captain-initiated dialogue.
4. Reserve one evening and play the seated conversation. Offer authored leave/stay choices when
   eligible. Save the selected outcome before its effects. Staying plays the lying-in-bed beat;
   either branch resolves one day and one upkeep, followed by its authored morning. Keep rapport,
   chapter effects and relationship choices idempotent. A reload may restart dialogue but must preserve
   the committed evening/outcome and apply its costs once.
5. Preserve independent concurrent relationships, Trust, released/ashore officer availability and
   existing pending scenes. Implement a compatible migration for prior saves; do not force completed
   confessions to replay. Inventory existing paired visits with CY50 and add paired seated/bed bindings
   only for their actual eligibility. Respect both participants' release, residence and consent.
6. Integrate draft lines and placeholders in a fresh private campaign pack immediately. Replace them
   under stable logical IDs as approved art/script arrive. Maintain per-character coverage and missing
   asset status. Update the technical format only with implemented fields.

## Verification and checkpoints

Check parser/packer rejection and old-pack compatibility with synthetic data. Exercise both evening
outcomes, ineligible stay, concurrent Hearts, pending confession, a release swap during a visit,
repeated completion, an old pending morning and shortage/upkeep through meaningful state tests.
Play First Watch, sign-on, optional Training and the real service prerequisites through both outcomes.
Use a second recruit and one existing paired visit, then sample each later intake on the same save.
At 844 × 390, check portraits over CGs, seated and bed framing, expressions, choices and safe areas.
Keep physical-device findings for CY37. Run lint, tests and build for the implementation.

## Done when

The implemented contract and evening flow work in the campaign with playable draft content, all fifty
solo arcs are mapped and supported, and paired exceptions are explicitly handled. Reload and release
replacement preserve choices and costs. CY49/CY50 statuses and pending final assets are recorded;
approved integration remains part of the shared cohort and CY36. Delete this packet with its Done row.
