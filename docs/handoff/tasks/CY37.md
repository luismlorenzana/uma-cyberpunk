# CY37 Private campaign release and iPhone play-through

## Why

Make the reviewed campaign playable and recoverable from the owner's iPhone Home Screen.

## Context

Use the approved output of [CY36](CY36.md), the [campaign release guide](../../technical/campaign-content.md#check-pack-and-select), and the [app save architecture](../../game/architecture.md#campaign-preview). The approved campaign needs a private hosted content source for the owner.

## Game implementation

- Integrate the private campaign release with the owner-only hosted app. Validate the selected pack and retain the prior release for rollback. Use the existing account and campaign save scopes. Exercise hosted authentication and the content and release integration only for Uma Cyberpunk.
- Make the agreed campaign entry easy to reach from the installed app. Test app install and update, save sync and backup recovery, and resume after an interrupted connection or version update. Verify the original campaign remains independently accessible.
- Run the iPhone checkpoint from First Watch through the first paid escort and appointments. Then play through the reveal, fleet launch, both breach entries and the last watch. Fix material issues with touch, performance, readability, pacing or resource balance in the feature that owns them. Retest affected segments after replacing the pack.

## Story and art

Review the approved dialogue, art and captions at landscape phone size. Check portraits, the bridge cues and the gate's console states during actual play. Use the finale and opening briefs to track any required swaps while retaining the agreed IDs.

## Done when

The owner can play from a fresh save and resume installed-app progress after a restart or compatible release change. The selected private release and its rollback both work, and the device review covers any-order recruitment, a local appointment, combat, and the ending. Close CY22–CY24 and CY28 when their recorded checks pass.
