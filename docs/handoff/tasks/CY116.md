**Milestone A · Engineering.** Start from the selected live four-act book, D93 opening, the [D94 design](../../design/homestretch-station.md) and [roadmap](../homestretch-station-roadmap.md). Work with [CY126](CY126.md) on contract and example rows.

## Deliver

1. Snapshot current build, book and content pins. Inventory existing actors, locations, port legs, seasonless day/night transitions, ship-watch writes, mission settlement, refits/logistics, projects, custody, scene branches and expedition transitions. Produce a machine-readable mapping from the old reader or producer to the planned reader. Include all command encounter families, the 25 duo entries and current endings.
2. Define one authoritative `absoluteWatch` in the campaign save. Date conversion is pure, three watches per day, four 30-day months. World pack pins month order and stable event IDs. Store absolute due/complete watches, phase and resolution IDs, with deterministic ordering when work and scenes are due together. Define an atomic advancement API used by travel, committed missions, waiting and evening settlements. Keep replay-local combat turns separate.
3. Define stable station, room instance, socket and berth IDs, station anchor and move, build queue, power allocation and work snapshots. Use one actor identity with resolved presence, custody, legal role, assignment and accommodation. Define a capacity ledger for temporary, permanent, fleet, base and secure placement.
4. Define a starter cutter and one persistent hull per Story duo. Store draft/commissioned, docked/parked/underway/servicing states, local supply, fitting and damage. Track the single active player-controlled voyage. Specify launch, load, refit, launch result, park, return and release transactions and idempotency keys. Freeze the craft and crew in existing combat snapshots.
5. Define versioned Story/calendar, room scene, navigation and hull command binding fragments with private fixture examples. Validate IDs, clock mapping, actor roles, phase, route graph, explicit fallback, exact hash, cutaway and portrait scopes, and compatible ancestry for content verification. Data written before this update gets deterministic defaults. Map legitimate in-flight travel, carried custody, active expedition, night, or replay across reload. Use the same four-act profile.
6. Set measurement targets from CY96 and the current app. Budget save parsing, worst-case 250 occupants, 280 berths, 25 persistent fleet records, history and state size, pages and look loading, and the repository's 180 KB gzip initial JavaScript gate. Keep room, agenda and fleet code behind their normal lazy entry points.

The compatibility and validators prove one advance and result settle once, supported retry and saved replay behavior, and reference coverage at full campaign scale.
