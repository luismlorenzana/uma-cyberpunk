## Authoring work

1. Establish one neutral design sheet per weapon/support class, showing silhouette, grips, mounting,
   mechanism, material and palette zones. Fit the approved armor's actual dimensions. Record which
   catalog entries reuse a base design and what changes distinguish them.
2. Provide inventory/workshop icons and the larger Hangar/deploy view for every catalog entry. Check
   the currently seven project recipe icons against these designs. Small icons must distinguish the
   item at displayed size. Text and stats remain generated by the game.
3. With CY57, make sprite-scale views and masks for the first legal melee, ranged, shield, support and
   Back-weapon rigs. Return grip/mount anchors and depth-order notes in the executable fixture. A
   painted concept sheet alone does not satisfy an attachment export.
4. Use reusable palette masks for body/base, accent, trim and emblem/material zones as needed. Preserve
   mechanical identity when adapting to a character. Keep the shared geometry available so an
   equipment replacement does not require repainting every character's entire sprite set.
5. Coordinate alternate grips/arm poses with CY59/CY60. Review an actual two-handed weapon, shield
   action and Back fire on the first campaign board. Resolve layering/scale before exporting the
   remaining families and per-character adaptations.

## Handoff and acceptance

Return part/visual IDs, design references, approved source hashes, dimensions, alpha, masks, native
sprite views, attachments, supported animations and comparison at board/icon size. Record exact
approval scope and all shared-design relationships. Use the existing private authoring Weapons
category for cast adaptations; keep generic campaign equipment sources privately in this repo when
appropriate. Album publication and campaign integration are separately recorded.

Done when every current catalog entry has an approved canonical design and usable UI export, every
required visible attachment is supported or explicitly represented by a reviewed shared treatment,
and the first campaign fitting/battle matches its inventory image. CY57 owns mechanical validation.
Delete this packet with its Done row after authoring acceptance.
