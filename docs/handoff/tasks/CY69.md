# CY69 General Art and Story handoff · Replace current campaign review backdrops

## Outcome and scope

Give the currently implemented Tier 1–5 campaign appropriate environments wherever its scenes still
use review plates. Keep the same quests, places, scripts, choices and save. Read
[CY52](CY52.md), the [implemented approved-source intake](../../technical/campaign-management.md), the
[art direction](../../design/art-direction.md) and the current private Story book and location bible.
Work in the game's general-art authoring content; Character Art owns every cast layer.

## Authoring work

1. Refresh this inventory from the current selected book, including any already replaced by CY67.
   Trace each bound scene to its actual activity and scripted setting. Check quest/context consumers
   and prerequisites; retain conditional scenes explicitly rather than presenting them as reachable.
2. With Story, classify each scene as ship interior, shore/civilian place, occupied facility/boarding
   context or another existing authored setting. Record time, occupancy/privacy, relevant anchors
   and required visual state. Return ambiguities to CY50/CY53/CY56; continue unambiguous groups.
3. Map approved common bridge, welcome, cabin, social, care, operations and civilian sources first.
   Carry their exact version/hash and scene-specific fit. Reuse the approved nineteen-location set
   where it represents the actual place; preserve custody/residence, two-berth and cabin continuity.
4. Produce a locked **new-source/reuse matrix** before bulk drawing. Each new request names a stable
   logical asset ID, real scene consumers, location/Story references, camera/lighting, quiet text and
   profile zones, character-layer contacts, required state and reusable scope. The first cohort is
   the real opening escort/occupied approach plus one private/public ship conversation and one shore
   service scene. Expand the reviewed matrix through the later ferry/tender services and all tiers.
5. Author only the uncovered settings in that matrix. Match approved character references and D66's
   Hardline Anime, colorful lived-in world. Keep the Captain as the undrawn viewpoint. Room-only
   backgrounds and separate props retain the current layering/portrait contract. Bespoke ground
   battle terrain, composed sprites and signatures follow CY57–CY63's separate executable contracts.
6. Return per-scene backdrop/placement changes as presentation patches with original records and
   proposed replacements. Preserve dialogue, cast, gates, script effects and existing character/face
   layers. A change to the actual place or suit staging is a Story/Development review item, not an
   automatic art migration. Reconcile CY65's wardrobe routing against the final setting matrix.

## Deliverables and completion

Return the full coverage matrix, reused source hashes, new approved native PNGs, actual size/alpha,
source versions, prompts/reference provenance, layer bounds, approval evidence and phone-size
captures. Development merges these patches into the current book, verifies fingerprints appropriate
to presentation-only changes and conditionally selects an immutable release. Retain current
CY54/CY65/CY66 work and leave gameplay/saves unchanged.

Done when every remaining in-scope review binding has an approved appropriate source or explicit
reviewed reuse, with source and integrated-release evidence. A list of draft paintings does not
complete integration. Physical iPhone acceptance stays CY37. Delete with its Done row.
